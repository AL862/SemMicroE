# Материалы преподавателя

Применить [общий навык](../microeconomics-seminar/SKILL.md). При решении задач читать [паттерны задач](../microeconomics-seminar/references/problem-patterns.md); для темы 5 — [модель](../microeconomics-seminar/references/seminar-5-model.md).

## Конспект презентации
- Каждый новый или изменённый PPTX обязательно сопровождается заново подготовленным согласованным конспектом всего выступления. Работа не завершена без этого файла.
- Единственный итоговый формат: Seminar_N_Conspect_Profesor.docx. Не создавать альтернативные TXT/PDF/HTML-конспекты. При порученном обновлении старые альтернативы удалять после проверки полного актуального DOCX.
- Для манеры Alexandru Leahovcenco прочитать полные статьи-образцы по [реестру](../microeconomics-seminar/references/course-resources.md), а не только список публикаций. Рабочие статьи не изменять.
- Заимствовать способ рассуждения: определить предмет → конкретная ситуация → последовательный механизм → расчёт/сравнение → следствие. Не переносить посторонние по теме утверждения, большие цитаты, опечатки и тяжёлые переводы; не приписывать автору новые факты.
- Писать связными абзацами как готовое устное объяснение. Один абзац развивает одну мысль, следующая фраза объясняет предыдущую. Переходы Considerăm / Aceasta înseamnă / Prin urmare применять по смыслу без механического повторения.
- Разделы соответствуют реальным слайдам по порядку и номерам. Объяснить каждую ключевую мысль, символ, сокращение, формулу и пример; дать экономический смысл, типичные ошибки, дополнительные пояснения, короткий вопрос с ответом и реалистичный хронометраж.
- При изменении состава слайдов пересобрать весь конспект. Он может раскрывать подробности, которые перегрузили бы слайд, но не заменяет объяснения на самом экране.
- Сохранять существующий DOCX без лишних версий и с прежней ссылкой. Новая версия конспекта сама по себе не требует правки утверждённого Moodle HTML.

## Самостоятельные решения задач
- Файл решений отдельно от конспекта презентации; он не подменяет DOCX и не является материалом для студенческого раздела скачивания.
- При отдельном поручении на решения читать точные условия указанного раздела HTML. Утверждённую страницу без соответствующего поручения не менять.
- При изменении задач Moodle одновременно актуализировать существующий файл решений: условия, периоды, единицы, подпункты, вычисления, таблицы, графики и выводы.
- Для Seminarul 5 источник текущих студенческих задач — раздел 5 файла 05_Seminarul_5_Moodle.html. Итог решений — существующий Seminar_5_Probleme_Solutii.pdf с прежним Drive ID и расположением.
- После записи повторно скачать и сверить HTML и решения. Для нового семинара состав отдельных DOCX/PDF-решений определяется поручением и стандартной структурой Materiale.
