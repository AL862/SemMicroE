# Materiale pentru curs

## Bibliografie

`Bibliografie_Microeconomie_Moodle.html` este pagina completă. Varianta `_FRAGMENT.html` este destinată inserării în conținutul unei pagini Moodle. Ambele conțin aceeași bibliografie cu 40 de cărți și trei referințe normative istorice. Căutarea și filtrul pe seminare ajută la selectarea lecturii. ISBN este afișat când a fost identificat pentru ediția indicată.

Titlurile bibliografice păstrează punctuația ediției. ISBN-urile nu sunt transferate între traduceri sau ediții diferite.

## Glosar

Glosarul conține **141 de termeni în 11 categorii**. Există trei variante ale aceluiași conținut:

- `Glosar de microeconomie.html` — consultare locală cu căutare și filtru pe seminar.
- `Glosar de microeconomie — Import XML.xml` — importul termenilor într-un glosar Moodle existent.
- `Glosar de microeconomie — Curs complet.mbz` — restaurarea unei activități complete de tip Glosar.

### Importul recomandat în glosarul existent

1. Deschideți **Glosar de microeconomie** în Moodle.
2. În meniul activității alegeți **Mai mult → Importă intrări / Import entries**.
3. Selectați fișierul `Glosar de microeconomie — Import XML.xml`.
4. Alegeți glosarul curent ca destinație și activați importul categoriilor.
5. Verificați numărul de înregistrări și cele 11 categorii după import.

Acesta este XML pentru **glosar**. Nu se importă în banca de întrebări și nu se încarcă în pagina Restaurare.

### Restaurarea MBZ

Folosiți **Restaurare / Restore** pentru fișierul MBZ. Acesta reproduce structura arhivei încărcate de dumneavoastră. În Moodle înregistrările glosarului sunt tratate drept conținut de utilizator. Opțiunea de includere a acestui conținut trebuie păstrată pentru a transfera termenii. Arhiva nu conține conturi personale sau date de autentificare. Autorul tehnic al termenilor nu este asociat unui cont inclus.

Dacă rolul Moodle nu permite restaurarea conținutului de utilizator folosiți importul XML de mai sus. Cele două metode sunt alternative. Nu este necesară importarea aceluiași conținut de două ori.

Arhiva și XML-ul au fost verificate structural față de codul modulului Moodle. Restaurarea efectivă în instanța autentificată Moodle nu a fost executată din acest mediu.
