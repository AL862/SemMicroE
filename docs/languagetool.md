# LanguageTool для проверки материалов

Исходный проект [languagetool-org/languagetool](https://github.com/languagetool-org/languagetool) подключён подмодулем `third-party/languagetool` на коммите `bc7e597ca2a147c1139012fbf5fd9662de8034ad`. Лицензия исходного проекта — LGPL 2.1 или новее. Это Java-приложение; добавление подмодуля не запускает сервер.

## Подготовка

Для готового дистрибутива LanguageTool 6.6 нужна Java 17+. В рабочее окружение скачан и распакован официальный архив:

- URL: https://languagetool.org/download/LanguageTool-6.6.zip
- Размер: 251998221 байт.
- SHA256 скачанного файла: `53600506b399bb5ffe1e4c8dec794fd378212f14aaf38ccef9b6f89314d11631`.

Архив и Java-библиотеки не добавлены в репозиторий. Его исходники подключены отдельно фиксированным подмодулем. Для запуска скачайте и распакуйте дистрибутив, перейдите в каталог LanguageTool-6.6 и выполните:

```bash
java -Xmx1024m -cp languagetool-server.jar org.languagetool.server.HTTPServer --port 8081
```

Без `--public` сервер слушает локальные подключения. Проверка доступности: `GET http://127.0.0.1:8081/v2/languages`; в списке должен присутствовать язык `ro`.

26 октября 2026 все 11 переработанных Moodle HTML проверены локальным LanguageTool 6.6 на румынском через CLI. HTTP-сервер не запускался. Исправлены реальные замечания к числительным и пунктуации. Формулы и экономические термины просмотрены вручную. Отсутствие всех языковых ошибок не утверждается.

## Проверка файла

Из корня SemMicroE:

```bash
python tools/check_course_text.py "Seminarul 1 — Obiectul de studiu și metodologia microeconomiei/01_Seminarul_1_Moodle.html" --language ro --output reports/seminar-1-language.json
```

Команда читает оригинал и создаёт JSON-отчёт. Исправления автоматически не применяются. Поддерживаются HTML, TXT, MD, нативный текст DOCX/PPTX и текстовый слой PDF. Для PDF нужен `pdftotext`. Слайды-картинки, сканы и динамические строки JavaScript требуют отдельной проверки/OCR.

По умолчанию используется только локальный сервер. Параметр `--server` позволяет явно выбрать другой сервер. Коды завершения: 0 — замечаний нет; 1 — есть замечания; 2 — проверка не выполнена из-за ошибки.

## Требования курса

Навык [languagetool-proofreading](../.agents/skills/languagetool-proofreading/SKILL.md) связывает проверку с правилами семинаров. Дополнительно отмечаются запятые в извлечённом тексте, cedilla вместо ș/ț, запрещённые выражения, псевдоиндексы и inline-обработчики событий.

Замечания LanguageTool требуют проверки преподавателем. Нельзя автоматически добавлять запятые или менять числа, единицы, формулы и смысл задачи. Для языка действует правило перестройки фразы без запятых из полного справочника курса. Выводы LanguageTool не являются проверкой экономического содержания.

Ограничения извлечения записываются в отчёт. Смещения LanguageTool относятся к UTF-16 внутри отправленного фрагмента; `chunk_start_codepoints` относится к символам извлечённого текста. Это не номера позиций исходного HTML.

## Без сервера

Готовый дистрибутив поддерживает проверку без сокетов:

```bash
java -Xmx384m -jar /path/to/LanguageTool-6.6/languagetool-commandline.jar -l ro -c utf-8 --json seminar.txt > report.json
```

Текст извлекается с пробелами между HTML-узлами. Динамические строки и подписи SVG дополнительно рассматриваются отдельно. Отчёт фиксирует фактический запуск CLI; это не подтверждение запущенного сервера или экономической корректности.
