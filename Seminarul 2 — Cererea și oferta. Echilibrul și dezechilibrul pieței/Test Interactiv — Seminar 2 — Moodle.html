Seminarul 2 — Cererea, oferta și echilibrul pieței

20 de întrebări · 4 variante A–D · 20 de secunde pe întrebare

Fiecare întrebare are un fragment HTML separat și patru texte pentru câmpurile de răspuns din Moodle Realtime Quiz.

  1. În «Textul întrebării», deschideți Unelte → Cod sursă și lipiți fragmentul HTML al întrebării.
  2. Copiați textele separat în Răspuns1–Răspuns4, în ordinea A–D.
  3. Selectați butonul radio indicat în rândul Corect.
  4. Completați câmpul Question time cu 20.

Cheia și HTML-ul răspunsului corect sunt afișate în panoul profesorului. Fragmentul HTML al întrebării include blocul verde și, unde este cazul, graficele.

Cheie: B · D · A · C · B · A · D · B · C · A · C · D · A · B · D · C · D · A · C · B

Literele corecte nu se repetă la întrebări consecutive. Distribuție: A — 5; B — 5; C — 5; D — 5.
