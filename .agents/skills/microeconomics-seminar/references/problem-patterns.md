# Паттерны задач

Читать вместе с общими правилами. Здесь находится единая дидактическая схема задач; предметные навыки не дублируют её.

## Решённая задача

Problemă → Date → Cerințe → Indicații pentru rezolvare → Rezolvare → Concluzie economică → при необходимости Tabel-sinteză → Exemplu practic → Pentru înțelegere mai profundă.

- Problemă: 1–2 предложения о ситуации и зависимости результата; не начинать с голой формулы.
- Date: при более чем двух-трёх данных таблица «Indicator | Semnificație | Valoare / modificare». Процентное изменение имеет направление и знак: scade cu 4% означает −4%, crește cu 5% означает +5%.
- Cerințe: обычно 2–3 коротких расчётных действия через Găsiți / Calculați / Determinați / Stabiliți. Связанные вычисления можно объединять. Не оставлять только список символов. Объяснение типа, причины и последствий выносить в Concluzie economică cerută. Исходный проверочный блок с обязательными подпунктами не сокращать.
- Indicații pentru rezolvare: именно это название; 2–3 опорных логических шага, применимое условие/формула и при необходимости типичная ошибка. Не подставлять числа и не выдавать промежуточный или конечный результат. Не превращать подсказки в мини-лекцию.
- Rezolvare: отдельный блок для каждого требования. Объяснить что ищем, зачем эта формула, откуда число, подстановку, вычисление, итог жирным и его экономический смысл. При важном знаке объяснить словами, например minus cu minus dă plus. Заполнить исходную таблицу/график.
- Concluzie economică: зелёный блок, отвечающий на вопрос о понятии, связи, причине или последствии. Число служит аргументом, а не заменой вывода. Для малого удельного налога распределение нагрузки объяснять через относительную эластичность при указанных предпосылках.
- Tabel-sinteză при нескольких результатах: «Indicator | Valoare / Calcul | Interpretare».
- Exemplu practic: отдельный нейтрально-серый блок после полного решения; объясняет результат, не вводит новую задачу.
- Pentru înțelegere mai profundă добавлять только при методической пользе. Например изменение выручки после изменения цены.

## Задача студенту

Тот же паттерн без Rezolvare и готового ответа:
Problemă → Date → Cerințe → Indicații pentru rezolvare → Concluzie economică cerută.

Последний блок содержит один ясный вопрос на понимание на основе расчётов. Не дублировать Cerințe.
Для новых аналогов сохранять метод и табличную/графическую форму, менять числа. По умолчанию два аналога каждого базового типа, если пользователь не задал другое. Не ставить два аналога одного типа подряд.

## Проверка вычислений и эластичности

При необходимости округлять расчёт до двух знаков, если источник/условие не требует другого; отображение дробей подчиняется общему языковому правилу курса.
Использовать только нужные для задачи отношения, не включать весь список как дополнительную теорию:

- Процентная реакция: ΔQd% = Eᵖd × ΔP%.
- Точечный коэффициент: коэффициент фактора в функции × фактор/Qd.
- Совместное малое изменение: ΔQd% ≈ Eᵖd × ΔPx% + Ei × ΔI% + Exy × ΔPy%.
- |Eᵖd| < 1 — inelastică; > 1 — elastică; = 1 — unitară.
- Exy > 0 — substituibile; < 0 — complementare; = 0 — independente.
- Ei > 0 — bun normal; 0 < Ei < 1 — реакция меньше пропорциональной; Ei > 1 — больше пропорциональной; Ei < 0 — bun inferior.
- Выручка: preț × cantitate. Относительный множитель: (1 + ΔP) × (1 + ΔQ), где изменения берутся как доли. При эластичном спросе снижение цены может увеличить выручку; при неэластичном — уменьшить.

Текстовая запись формул здесь — справочник для агента. В учебном результате применять настоящие индексы согласно общему правилу.
Классификацию объяснять словами через сравнение абсолютного значения с 1; не употреблять тяжёлую фразу «Clasificăm sensibilitatea la preț prin modulul coeficientului».
При сравнении спроса и предложения сравнивать абсолютные значения коэффициентов; меньшая величина означает относительно меньшую эластичность.
