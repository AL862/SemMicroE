Теория изложена заново. Все ответы на проверочные блоки раскрываются через `details`. У новых задач есть условия и подсказки; ключи находятся в данных генератора и не выводятся в студенческие страницы. В каждом семинаре одна интерактивная модель. Скрипты используют addEventListener.

## Повторная сборка

Из корня репозитория:

```bash
python3 tools/moodle-course/build.py
```

Генератор использует стандартную библиотеку Python. Учебные данные редактируются в `tools/moodle-course/data/N.json`. `model_fallback` хранит начальное статическое состояние модели для чтения без JavaScript. После изменения формул или начального состояния его нужно обновить вместе со скриптом.

Для отдельной математической проверки нужен SymPy:

```bash
python3 tools/moodle-course/verify_calculations.py
```

## Проверки и ограничения

- 59 независимых проверок выбранных вычислений и оптимумов: `calculation-checks.json`.
- Chromium: все11страниц на320/390/768/1150px; раскрытие ответов, ползунки, переключатели, отсутствие общего переполнения и ошибокJS: `browser-checks.json`.
- LanguageTool6.6 CLI, языкro, все11статических текстов. Реальные замечания исправлены вручную. Формулы и термины дают ложные срабатывания. Число оставшихся замечаний не является числом ошибок.
- Фактическую вставку, сохранение и повторное открытие в Moodle не проверяли: доступа к редактору Moodle нет. Если Moodle удаляет скрипты интерактивность требует разрешений администратора; обычные тексты и раскрывающиеся ответы используют HTML.

Рабочая связь сPDFстраницами и использованные методические источники записаны в `source-register.json`. Это технический реестр для сопровождения курса.
