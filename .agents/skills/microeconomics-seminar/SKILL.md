# Подготовка семинаров Microeconomie

## Источник правил
Инструкции из корневого README.txt перенесены без изменения содержимого в [полные правила](references/course-rules.txt). Это их постоянное расположение после миграции. Исторические упоминания README.txt внутри справочника означают этот файл. Не создавать заново удалённые корневые README.
[Указатель разделов](references/rules-index.md) помогает открыть нужные части. Сначала читать общие правила 0–6 и требования нужного формата. Последнее прямое указание пользователя имеет приоритет над сохранённым справочником.

## Порядок работы
1. Уточнить номер семинара, тему и требуемые результаты по запросу. Определить тип: Moodle, презентация преподавателя, конспект, решения, тест или индивидуальная работа студента.
2. Проверить тему по Curriculum Universitar. Просмотреть существующие материалы нужного Seminarul N и подпапки Materiale на личном Google Drive. GitHub может содержать неполный перенос; отсутствие файла в GitHub не означает отсутствие источника на Drive.
3. До отбора содержания прочитать относящиеся к теме страницы Aurelia Tomșa / Seminar_N_Sursa_*.pdf, включая таблицы, определения, формулы, графики и разрешённые проверочные задания. OCR сверять с изображениями страниц. Неразборчивые значения не восстанавливать догадкой.
4. Сохранить связь выводов со страницами источника. Приоритет: Curriculum → основной учебник → дополнительные источники → существующие материалы → собственные объяснения.
5. Отдельно решить и проверить исходные задачи, затем составить план. Сохранять числа, функции, названия, единицы, подпункты, таблицы и геометрию заданий. Новые аналогичные задачи явно отличать от исходных.
6. Создать материалы соответствующим навыком ниже. Проверить согласованность темы, терминов, символов, условий, чисел, единиц и выводов между связанными файлами.
7. Обновлять существующие файлы; не создавать случайные FINAL, _v2, (1). Архивировать промежуточные версии по правилам курса. Выполнять запись только в пределах поручения пользователя и подтверждать её повторным чтением.

## Общие требования
- Учебный текст — простой и грамматически правильный румынский с ă â î ș ț. Объяснять понятие до сокращения и каждое обозначение до расчёта.
- Рассуждение: экономическая ситуация → причина → понятия и символы → формула → короткий пример → интерпретация.
- В видимом учебном тексте не использовать запятые: перестраивать предложения грамматически, а не удалять необходимые знаки механически. Диакритики ș/ț сохраняются. Аргументы функций разделять точкой с запятой; дроби представлять точными обычными дробями либо словами. Разделители JS/CSS/JSON не трогать.
- Не употреблять «cheltuiala». Вместо «ceteris paribus» писать «ceilalți factori rămân neschimbați». Конкретно объяснять допущения вместо «în modelul simplificat al seminarului».
- Основные экономические символы — прописные обычного размера. Буквенные индексы — строчные уменьшенные: настоящие sub/sup в HTML и типографические индексы в DOCX/PDF/PPTX. Подчёркивания не имитируют индексы.
- Цвета: заголовки #123B5D и #1F6388; спрос/потребитель #1080E4; предложение/производитель #FF650B; равновесие/вывод #3F8F1F; дефицит #C94A4A; избыток #C58A00.
- Для учебных семинаров не создавать studii de caz, sarcini analitice и темы рефератов. У индивидуальных студенческих работ есть отдельные правила раздела 17: не переносить запреты и формат преподавательских презентаций механически на эти работы.
- Проверять арифметику, экономические условия и выводы вручную. LanguageTool даёт языковые замечания, но не доказывает правильность экономики.
- Корректное сохранение в GitHub и на Drive подтверждать отдельно по фактически выполненным действиям.
