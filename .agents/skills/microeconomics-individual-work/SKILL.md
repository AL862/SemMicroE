# Индивидуальная работа студента

Прочитать [общие правила](../microeconomics-seminar/SKILL.md) и весь раздел 17, включая 17.8–17.9, в [справочнике](../microeconomics-seminar/references/course-rules.txt). Это отдельный стандарт: преподавательские слайды-картинки здесь не применяются.

- Одна утверждённая тема на студента. Румынский язык, выступление 10 минут, ориентир 8–10 содержательных слайдов.
- Эталон: «Șablon — Lucrare individuală la Microeconomie.pptx» из Lucrări individuale. Формат PPTX 16:9. Текст, формулы, схемы, таблицы, стрелки и графики остаются нативными и редактируемыми. Служебный слайд-инструкцию удалить перед сдачей.
- Структуру адаптировать к теме: титул → введение → понятия → механизм → визуальная модель → пример/кейс → данные/сравнение → последствия → выводы → библиография. Расчёты не обязательны. Пустых слайдов не оставлять.
- Темы из заключительных разделов учебника можно предложить преподавателю отдельно для утверждения. Не добавлять их автоматически в Moodle-страницы семинаров.
- Исследование на 100% выполнимо через интернет. Не требовать собственных опросов, интервью, посещений магазинов/предприятий и наблюдений на месте.
- Использовать опубликованные официальные данные и онлайн-источники либо явно обозначенные гипотетические сценарии. Для реальных данных указать автора, ссылку, период и единицы. Придуманные данные на студенческих слайдах обозначать «Date ipotetice — exemplu didactic».
- Каждая тема содержит экономический вопрос, понятное онлайн-действие, доступный источник, ожидаемый результат и интерпретацию. Для оценки эластичности одного ряда цен недостаточно: нужны сопоставимые цены и количества.
- Финальное имя: «Lucrare individuală — [Titlul temei] — [Nume Prenume].pptx».
- Инструкцию для Moodle оформлять по утверждённому «Instrucțiune — Lucrări individuale pentru studenți.html». Реестр файла и ссылка в 17.9.
- Прямая вставка TinyMCE: один корневой div, важные стили inline, нативные вложенные details/summary. Не полагаться на style/head или JS. Для текущего каталога сохранить пять семинаров по три темы, затем структуру слайдов, электронные источники и нумерованный checklist.
- Использовать реальные ссылки. После сохранения проверить именно страницу Moodle; локальный HTML не доказывает, что редактор сохранил оформление.
