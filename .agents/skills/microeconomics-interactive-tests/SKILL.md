# Интерактивный тест

Применить [общий навык](../microeconomics-seminar/SKILL.md). Эталон интерфейса указан в [реестре](../microeconomics-seminar/references/course-resources.md). Для копируемого информационного HTML применять процедуру TinyMCE из навыка Moodle.

## Вопросы и ответы
- База: Teste grilă/Teste и Întrebări de verificare соответствующего источника. Ответ сверить с теорией; старые тесты и Kahoot использовать как дополнительный банк.
- Создавать адаптированную проверочную ситуацию, а не механическую копию: уточнять вопрос, превращать открытый в выбор ответа, использовать короткую интерпретацию формулы, графика или изменения показателя.
- Четыре различных правдоподобных варианта и ровно один правильный ответ. Не включать длинные вычисления; короткие должны укладываться во время вопроса.
- В преподавательском блоке хранить тематический источник, а при наличии номер исходного пункта и страницы. Проверенные уже утверждённые вопросы можно сохранить.
- Два соседних вопроса имеют разные правильные буквы. При необходимости переставить варианты следующего вопроса и обновить все соответствия ключей.
- Фиксированное соответствие: A = Răspuns1; B = Răspuns2; C = Răspuns3; D = Răspuns4. В Moodle копируется сам ответ без буквенного префикса.
- В исходных проверочных блоках самой страницы семинара порядок не менять: это правило относится к отдельной адаптированной версии теста.

## Автономный HTML и карточка
- Один автономный HTML в корне семинара: «Test Interactiv — Seminar N — Moodle.html». Структура и CSS совпадают с эталоном; внешних зависимостей нет.
- В начале: тема, число вопросов, вариантов, время и краткая инструкция переноса. Текущие значения задаёт поручение. Историческая конфигурация 10.10.2026: семинар 1 — 25×20 секунд; 2 — 20×20; 3 — 25×25; 4 — 25×25.
- Каждая карточка содержит номер, тему, предпросмотр вопроса, поле полного HTML, «Copiază HTML», скачивание фрагмента и четыре отдельных поля A–D с «Copiază».
- В копируемом вопросе только условие, пояснения и необходимые изображения. Правильный ответ, ключ, время и примечания об источнике — отдельно для преподавателя.
- HTML ответа с объяснением и кнопкой копирования находится в свёрнутом преподавательском блоке.
- Студенческий вопрос оформлять inline: фон #eaf7ec, рамка 1px #b7ddb9, левая полоса 6px #2e7d32, радиус 12px, отступы 20px 22px. Сначала тема зелёными прописными, затем крупный полужирный вопрос; график внутри того же блока.
- Предпросмотр, значение поля и скачиваемый фрагмент должны совпадать. Изображения встроить в файл и копируемый HTML без временных локальных ссылок.
- В полях ответов без форматирования использовать словесные обозначения согласно общему правилу.
- При отказе Clipboard API применить резервное копирование; при его отказе выделить весь текст и показать «Selectat — Ctrl+C».

## Проверка
Проверить смысл и единственность ответа, правдоподобие отвлекающих вариантов, отсутствие дублей, общий и локальные ключи после перестановок, соседние буквы, нумерацию, время, HTML-экранирование, каждую кнопку и её поле, переходы к вопросам и доступность изображений.
Существующий итоговый HTML обновлять на месте. Старые файлы удалять только по прямому поручению после извлечения нужного содержания и проверки нового файла.

## Нативные форматы Moodle

- Если поручен MBZ, создавать резервную копию активности Realtime Quiz по предоставленному рабочему образцу, а не переименованный XML или ZIP с произвольными файлами. Проверять XML, связи ID, пути, индекс архива и длины файлов. Данные студентов не включать.
- MBZ восстанавливается как активность через Restore. Для импорта вопросов в банк обычного Moodle Quiz предоставлять отдельный Moodle XML с типом multichoice и ровно одним ответом со100% веса. Не утверждать, что импорт XML сам создаёт активность.
- Актуальный выпуск: `[2] Teste interactive pentru Moodle`. Имена файлов и активностей: `Test interactiv - Seminarul N. Titlul temei.mbz`. XML с теми же именами — в подпапке `Import întrebări Moodle XML`.
- Пользовательский объём этого выпуска:11тем по25вопросов. База — проверочные блоки, решённые упражнения и выводы темы; дополнить понятными прикладными вопросами. Ключи и связь с учебными разделами хранить отдельно от HTML вопроса.
- После перестановки вариантов проверять полное совпадение ключей в MBZ, XML и преподавательском реестре. Для сохранения подготовленных букв не перемешивать ответы и вопросы при использовании.
- По последнему указанию пользователя все вопросы Realtime Quiz имеют25секунд без исключений. В стандартном Moodle XML индивидуальные таймеры не передаются.
- Сборка и проверки: `tools/moodle-quizzes/`. Локальную проверку пакетов отличать от фактической успешной реставрации на сервере Moodle.


- При сборке MBZ проверять правило convert_helper::detect_moodle2_format: в первых200байтах moodle_backup.xml должны находиться декларация `<?xml version="1.0" encoding="UTF-8"?>` с двойными кавычками, `<moodle_backup>` и `<information>`. Обычная успешная проверка XML-парсером этого не гарантирует. Регрессионная проверка: `python3 tools/moodle-quizzes/test_format_detection.py`.

- Подпись номера в карточке: «Întrebarea N / 25». Между словом и номером и по обе стороны слэша стоят пробелы. При новом объёме менять знаменатель согласованно.
