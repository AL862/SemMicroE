# Интерактивный тест

Прочитать [общие правила](../microeconomics-seminar/SKILL.md), разделы 10.1–10.5 и 17.9 в [справочнике](../microeconomics-seminar/references/course-rules.txt).

1. Прочитать Teste grilă/Teste и Întrebări de verificare из соответствующего источника. Сверить ответ с теорией. Существующие тесты и Kahoot — дополнительный банк.
2. Адаптировать вопросы для проверки знания и понимания. Ровно четыре различных правдоподобных варианта и один правильный ответ. Не включать длинные вычисления и запрещённые аналитические задания. Источник вопроса фиксировать в преподавательском блоке.
3. Один автономный файл в корне семинара: «Test Interactiv — Seminar N — Moodle.html». Эталон структуры/CSS — тест семинара 3. Работает локально без внешних зависимостей.
4. В начале указать тему, число вопросов, варианты, время вопроса и инструкцию переноса. Число и время выбирать по текущему поручению; исторические значения 1–4 сохранены в 10.3.
5. Карточка: номер → тема → предпросмотр зелёного блока → полный HTML вопроса → «Copiază HTML» и скачивание фрагмента → отдельные поля и копирование вариантов A–D.
6. HTML студенческого вопроса содержит только условие и нужные изображения. Ключ, правильный ответ, время и служебные замечания — отдельно для преподавателя. Обратная связь с объяснением — в свёрнутом преподавательском блоке.
7. Зелёный блок использует встроенные inline-стили: фон #eaf7ec; рамка #b7ddb9; левая полоса 6px #2e7d32; радиус 12px; отступы 20px 22px. Полный образец в 10.2. Предпросмотр, textarea и скачиваемый фрагмент совпадают.
8. A = Răspuns1; B = Răspuns2; C = Răspuns3; D = Răspuns4. В Moodle копируется текст без буквенного префикса. У двух соседних вопросов правильные буквы различаются; после перестановки обновить все ключи.
9. Использовать addEventListener. При отказе Clipboard API применять резервный механизм, затем выделение текста с «Selectat — Ctrl+C». Проверить каждую кнопку и её поле.
10. Изображения встроены в автономный файл и копируемый фрагмент. Не терять геометрию визуальной задачи.
11. Румынский текст без запятых. В HTML настоящие индексы; в полях без форматирования — понятные словесные обозначения без псевдоиндексов _ и ^.
12. Проверить единственность ответа, источники, отсутствие дублей, соседние ключи, нумерацию, время, экранирование, локальные переходы и копирование. Порядок исходных проверочных блоков на самой странице семинара не переставлять: правило перемешивания относится к адаптированному интерактивному тесту.
