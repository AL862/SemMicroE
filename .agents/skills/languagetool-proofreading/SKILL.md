# Проверка текста LanguageTool

1. Прочитать [общие требования курса](../microeconomics-seminar/SKILL.md), особенно правила языка и пунктуации. Подключённый исходный код LanguageTool находится в third-party/languagetool; это Java-приложение, а не встроенный инструмент ChatGPT.
2. Для реальной проверки нужен работающий сервер LanguageTool. Инструкции: docs/languagetool.md в корне проекта. По умолчанию команда использует локальный http://127.0.0.1:8081. Не утверждать, что проверка выполнена, если сервер недоступен.
3. Запуск из корня проекта:
   python tools/check_course_text.py "путь/NN_Seminarul_N_Moodle.html" --language ro --output reports/seminar-N-language.json
4. Инструмент читает текст и создаёт отчёт. Исходные файлы не изменяются. По умолчанию материалы не передаются внешнему сервису; иной --server является явным выбором пользователя.
5. LanguageTool проверяет язык, но не экономику, числа, источники, логику графиков и полноту семинара. Дополнительные проверки курса отмечают запятые, неправильные диакритики, cheltuiala, ceteris paribus, псевдоиндексы и inline-обработчики.
6. Замечания просматривать вручную. Не принимать автоматически предложения добавить запятые: согласно курсу фразу нужно грамматически перестроить. Сохранять числа, единицы, имена и формулы. Профессиональные термины могут давать ложные срабатывания.
7. HTML: проверяется извлечённый статический текст. Строки JavaScript, textarea с кодом, текст изображений и все состояния интерактивов требуют отдельной проверки. DOCX/PPTX: только нативный текст; слайды-картинки требуют OCR и визуального чтения. PDF: только текстовый слой, нужен pdftotext.
8. Код завершения 0 — замечаний нет; 1 — есть замечания для просмотра; 2 — проверка не выполнена из-за ошибки. Отчёт содержит контекст и разделённые результаты LanguageTool/правил курса. Смещения LanguageTool внутри фрагментов измеряются в UTF-16, а chunk_start_codepoints — в символах извлечённого текста; они не являются позициями исходного HTML.
